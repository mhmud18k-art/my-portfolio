Selected work

CosmosBilingual · React 19 · Canvas

A solar-system explorer in Arabic and English with full right-to-left support. The eight planet surfaces are drawn procedurally on a 2D canvas from real astronomical coordinates — Caloris Basin at 30.5°N, the Great Red Spot at 22°S — so there is no image to fail to load and nothing to license. Canvas over WebGL on purpose: eight simultaneous WebGL contexts exceed the browser limit and the oldest get dropped.

Darakom · داركمFirebase · Vanilla JS · Shipped

A live property listing site for a real-estate office in Damascus, currently carrying 33 properties. Visitors filter by neighbourhood, type and price, then message the office on WhatsApp about a specific property — the message already says which one. Behind it, an admin dashboard for the office, gated by Firebase Auth. Deliberately no framework and no build step: plain ES modules the office can hand to anyone.

Malaabi · ملعبيProduct · Flutter app in progress

Book the pitch, find the match. Football, basketball and padel. It starts from a problem every player knows: a free pitch and no opponent, or a team ready and nowhere to play — either way, a match that never happens. Teams post a challenge with format, level, time and terms; others accept it. The web version is live as the concept made tangible; the app is in build.

How I work

Arabic is a first-class language

Not a translation target. Direction, numerals, typography and element order are designed for it from the start — not mirrored afterwards.

Accessibility is part of the build

Not a pass at the end. Focus rings stay, contrast ratios get measured against the background, and reduced-motion preferences are honoured.

The simplest thing that holds

A framework earns its place or it doesn't ship. One project above is plain ES modules because that is exactly what the job needed.
